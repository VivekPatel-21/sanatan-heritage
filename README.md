# Sanatan Heritage

Stories, wisdom and traditions of Sanatan Dharma.

## Website

The first version contains the homepage: an introduction, foundational ideas, divine traditions, sacred literature and a coming-soon story collection. More pages will be added gradually.

Live site: https://sanatan-heritage.vivopatel1304.chatgpt.site

## Preview locally

Run `python3 -m http.server 8000` in this folder, then open http://localhost:8000.

## Files

- `index.html`: homepage content and navigation
- `style.css`: responsive maroon, ivory and antique-gold theme
- `temple.webp`: optimized AI-generated illustrative temple artwork; not a photograph of an identified temple

## Editorial approach

Identify sources, acknowledge differences among Hindu traditions, and distinguish scriptural accounts, regional traditions and retellings. Stories will be supplied by the project owner.

## Publishing

This repository is a copy of the website source. Updating GitHub does not automatically update the hosted Site; publication is handled separately.
