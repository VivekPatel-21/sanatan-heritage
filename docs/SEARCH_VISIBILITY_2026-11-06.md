## Search Console verification checklist

1. Open https://search.google.com/search-console and select the verified domain property for shreembala.com. This repository cannot authenticate a Search Console property.
2. In Sitemaps, submit https://www.shreembala.com/sitemap.xml and check the fetch and discovered URLs.
3. Inspect the homepage, stories, scriptures, deities and representative complete readers. Check Google-selected canonical, allowed crawling, and indexing state.
4. In Performance, review clicks, impressions, queries, pages and CTR over comparable periods.
5. In Core Web Vitals, examine real mobile metrics; use PageSpeed Insights for representative pages and Google's Rich Results Test for BreadcrumbList.
6. Check indexing and enhancement reports again after Google recrawls. Structured data and sitemap entries do not guarantee rich results or indexing.
